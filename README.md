# My Missing List

Quero criar um projeto, que será algo simples de inicio, e foco em ser de acesso rápido e descomplicado.

Será uma lista de itens colecionaveis(focado em livros, revistas, mangas e etc), mas focando nos itens faltantes. Por exemplo: eu crio uma lista de mangas que faltam de dragon ball, e usaria isso para checar caso em vá em uma biblioteca/livraria/sebo.

Essa aplicação será algo bem simples, com dados salvos localmente no dispositivo e sendo uma PWA de inicio.

O ideal é usarmos shadcn ui, e mais adiante nos falamos sobre estilização.

Organização: suportar tanto listas organizadas por coleção ou série (com volumes numerados para marcar o que falta) quanto itens avulsos.
